# Neon Hex

Рогалик-выживач: кибермаг против орд нанозомби. TypeScript + PixiJS v8 + Vite.

## Запуск в Codespace
    npm install
    npm run dev

Открыть проброшенный порт 5173 (вкладка Ports).

## Деплой
Settings → Pages → Source: GitHub Actions. Каждый пуш в main собирает и выкладывает игру.

## Управление
Палец в любом месте экрана — плавающий джойстик, кнопка «Рывок» справа внизу. На клавиатуре WASD или стрелки, рывок — пробел или Shift, выбор карточки 1/2/3, реролл снаряжения — R.

## v1.0
- Меню в стиле Диабло: титул, карта из 5 локаций, мастерская, испытания, достижения, настройки
- 5 локаций со своим полом, декорациями, туманом и светом; по 9 врагов и боссу на каждой
- 12 типов поведения врагов: стрелки, рывки, взрывы, деление, призыв, лечение, телепорт, кислота
- Боссы с паттернами и фазой ярости, элита с сундуками, святилища, омуты исцеления
- 24 оружия (6 школ × 4) с компиляциями, сеты 2/4
- Сохранения в localStorage: осколки, 11 улучшений мастерской, 15 звёзд, 25 достижений

## v1.1
- Графика «не совсем пиксель»: спрайты сглажены Scale2x ×4 с объёмным шейдингом, живописные полы, мягкие эффекты
- Процедурный звук и генеративная музыка на каждую локацию (WebAudio, без файлов)
- 6 классов магов, сложности Кошмар и Ад, бесконечный режим, испытание дня с модификаторами
- Редкость лута (обычный/магический/редкий/легендарный), 12 легендарок, гоблин-майнер
- Арсенал в меню, билд на паузе, обучение в первом забеге
- PWA: установка на домашний экран, офлайн; перенос сохранения кодом

## v1.2
- 3D-пиксель: спрайты и полы освещаются по карте высот (нормали, свет сверху-слева, 5 тонов с дизерингом, холодные тени и тёплые блики)
- Камера выровнена по пиксельной сетке экрана — чёткие пиксели не дрожат
- Сортировка по глубине: маг и враги заходят за колонны, надгробия, жаровни
- Ошмётки летят по дуге и отскакивают от пола
