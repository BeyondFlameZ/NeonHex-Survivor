# Neon Hex

Рогалик-выживач: кибермаг против орд нанозомби. TypeScript + PixiJS v8 + Vite.

## Запуск в Codespace
    npm install
    npm run dev

Открыть проброшенный порт 5173 (вкладка Ports).

## Деплой
Settings → Pages → Source: GitHub Actions. Каждый пуш в main собирает и выкладывает игру.

## Управление
Палец в любом месте экрана — плавающий джойстик, кнопка «Рывок» справа внизу. На клавиатуре WASD или стрелки, рывок — пробел или Shift, выбор апгрейда 1/2/3.
