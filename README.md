# Neon Hex 2.0

Мультяшный 3D-экшен «выживи против орды»: шесть кибермагов против Бездны.
Свой WebGL2-движок (тун-шейдинг, контуры, инстансинг), TypeScript, Vite, Capacitor 8.

## Запуск
```
npm install
npm run dev
```

## Структура
- `src/gl` — движок: рендерер, геометрия, текстуры
- `src/game` — бой: герои, враги, оружие, импланты, протоколы, арены
- `src/meta` — сохранения, экономика, задания, боевой пропуск
- `src/ui` — HUD, выбор улучшений, хаб и меню, портреты героев

## Публикация
Сборки для iOS и Android — workflow **iOS** и **Android** в GitHub Actions (Mac не нужен).
Пошагово — `store/GUIDE.md`, тексты для сторов — `store/LISTING.md`.
