# Публикация Neon Hex в App Store и Google Play — без Mac

Всё делается с iPad: Safari + Codespaces + GitHub Actions.
Приложение — та же веб-игра, упакованная в нативную оболочку **Capacitor 8**.
iOS собирается на облачном Mac GitHub (`macos-26`, Xcode 26), Android — на облачном Linux.

## 0. Обновить проект (один раз)
```
f=$(ls -t *.zip | head -1); unzip -o "$f" && rm "$f"
npm install
npm run build
git add -A && git commit -m "native" && git push
```
`npm install` **обязателен**: появились новые пакеты, и без обновлённого `package-lock.json` сборки упадут.

## 1. App Store

### 1.1 Аккаунт разработчика — $99 в год
Приложение **Apple Developer** на iPhone/iPad → Account → **Enroll Now**. Нужен Apple ID с двухфакторной защитой.
Подтверждение занимает от нескольких часов до пары дней.

### 1.2 Team ID
developer.apple.com → Account → **Membership details** → **Team ID** (10 символов).

### 1.3 Идентификатор приложения
developer.apple.com → Certificates, IDs & Profiles → **Identifiers** → «+» → App IDs → App →
- Description: `Neon Hex`
- Bundle ID: Explicit, `com.beyondflamez.neonhex`

### 1.4 Карточка приложения
appstoreconnect.apple.com → **Приложения** → «+» → Новое приложение:
- Платформа iOS, название `Neon Hex`, основной язык — русский
- Bundle ID — выбрать `com.beyondflamez.neonhex`, SKU — `neonhex`

### 1.5 API-ключ для облачной сборки
App Store Connect → **Пользователи и доступ** → **Интеграции** → App Store Connect API → **Ключи команды** → «+»:
- Имя `GitHub`, доступ **Admin** (нужен для облачной подписи)
- Запиши **Key ID** и **Issuer ID**
- **Скачай .p8** — скачать можно только один раз!

### 1.6 Секреты в GitHub
Репозиторий → Settings → Secrets and variables → **Actions** → New repository secret:

| Имя | Значение |
|---|---|
| `APPLE_TEAM_ID` | Team ID из п. 1.2 |
| `ASC_KEY_ID` | Key ID из п. 1.5 |
| `ASC_ISSUER_ID` | Issuer ID из п. 1.5 |
| `ASC_KEY_P8` | содержимое .p8 целиком, со строками BEGIN/END |

Как достать текст .p8 на iPad: загрузи файл в корень Codespace, затем
```
cat AuthKey_*.p8
```
Скопируй вывод в секрет, потом удали файл: `rm AuthKey_*.p8` (в git он и так не попадёт).

### 1.7 Сборка
GitHub → **Actions** → **iOS** → Run workflow. Занимает 10–20 минут.
Через 10–30 минут после зелёной галочки билд появится в App Store Connect → **TestFlight**.

### 1.8 Тест на своём iPhone
App Store Connect → TestFlight → Внутреннее тестирование → «+» группа → добавь себя.
Поставь приложение **TestFlight** из App Store — игра придёт туда.

### 1.9 Страница и отправка на проверку
Заполни по `store/LISTING.md`: скриншоты, описание, ключевые слова, категорию, URL политики, раздел «Конфиденциальность приложения» → «Данные не собираются», возрастной рейтинг, цену «Бесплатно».
Затем выбери билд → **Добавить для проверки** → **Отправить**. Проверка обычно занимает 1–3 дня.

## 2. Google Play

### 2.1 Аккаунт разработчика — $25 один раз
play.google.com/console → личный аккаунт → оплата и проверка личности (документ).

### 2.2 Ключ загрузки (один раз, в Codespace)
```
keytool -genkeypair -v -keystore upload.jks -alias upload -keyalg RSA -keysize 2048 -validity 10000
base64 -w0 upload.jks
```
Придумай пароль. Если спросит пароль ключа — нажми Enter, будет тот же.

Секреты в GitHub:

| Имя | Значение |
|---|---|
| `ANDROID_KEYSTORE_BASE64` | вывод `base64` целиком |
| `ANDROID_KEYSTORE_PASSWORD` | пароль |

**Сохрани `upload.jks` и пароль** вне Codespace: правый клик по файлу → Download → в «Файлы»/iCloud.
Без них обновлять игру не получится, пока не сбросишь ключ через поддержку Google.

### 2.3 Сборка
Actions → **Android** → Run workflow. Внизу страницы запуска — артефакт `neonhex-android-N` (zip):
- `neonhex-N.aab` — для Google Play
- `neonhex-test-N.apk` — для установки напрямую на Android-телефоны друзей

### 2.4 Карточка и анкеты
Play Console → **Создать приложение** (игра, бесплатная) → раздел «Контент приложения»:
политика конфиденциальности, реклама «нет», безопасность данных, рейтинг, целевая аудитория (13+) — всё по `store/LISTING.md`.

### 2.5 Закрытое тестирование — обязательно для новых личных аккаунтов
Правило Google: **минимум 12 тестировщиков, подписанных непрерывно 14 дней**, только потом можно запросить выход в продакшен.
1. Тестирование → Закрытое тестирование → создать трек.
2. Загрузить `.aab` вручную — первую загрузку API не примет. Подписание приложений Google Play — оставить включённым.
3. Добавить почты тестеров, разослать ссылку-приглашение. Возьми 15–20 человек с запасом: если число упадёт ниже 12, отсчёт начнётся заново.
4. Через 14 дней на панели появится «Запросить доступ к рабочей версии».

### 2.6 Автозагрузка (по желанию, после первой ручной)
Сервисный аккаунт Google Cloud с доступом к Play Console → JSON → секрет `PLAY_SERVICE_ACCOUNT_JSON`.
После этого каждая сборка сама падает черновиком во внутреннее тестирование.

## 3. Обновления
1. Подними версию в `package.json` (`"version": "1.3.1"`).
2. Запушь и запусти оба workflow. Номер сборки ставится автоматически.

## 4. Если что-то упало
Открой красный запуск в Actions → красный шаг → скопируй последние 30–40 строк лога и пришли — разберёмся.

## 5. Если ты в России
- Карты российских банков сторы не принимают.
- Про Apple: по отзывам разработчиков, взнос иногда проходит через приложение Apple Developer с оплатой с баланса Apple ID. Гарантии нет.
- Про Google: регион документа для проверки личности должен совпадать с регионом платёжного профиля. Обычно нужна карта и документы другой страны.
- Альтернатива для Android: **RuStore** — регистрация разработчика бесплатная, туда подходит тот же `.aab`/`.apk` из сборки.
